# Changelog

## 0.1.0 — initial release candidate (2026-11-07)

- Add a native OpenCode V2 server plugin targeting SDK and host 2.2.5.
- Review a narrow inspection grammar with an explicitly selected independent model; require strict output parsing and independent local policy for every allow.
- Correlate full shell input with native source identifiers; preserve explicit deny and leave other permissions unchanged.
- Fall back to ask on uncertainty, invalid configuration, provider errors, deadline, overload and unload. Bound unsettled reviews to eight.
- Keep context opt-in and restricted to fixed intent labels. Disable approval caching and command logging.
- Supply standalone ESM packaging, deterministic security regression tests, an isolated native smoke with an inert shell and controlled loopback HTTP provider, and pinned CI.

The operator authorized npm publication and accepted the two documented moderate transitive dependency advisories. Remote-provider, real scanner, interactive-client and private reporting checks are deferred until after release; production acceptance remains incomplete. See [verification](docs/VERIFICATION.md) and the [release checklist](docs/RELEASE-CHECKLIST.md) for evidence and publication status.
